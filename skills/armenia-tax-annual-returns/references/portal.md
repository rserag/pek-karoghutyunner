# Annual-return portal verification

Use https://file-online.taxservice.am/ in Chrome through an available browser tool. This reference does not contain tested annual-form input IDs or direct form routes. The 2026-10-05 research session was expired before the annual catalogue could be inspected; annual controls, signatures and persistence behavior remain unverified. Inspect the current UI before acting.

## Find the correct report

[SRC's electronic-report catalogue](https://www.src.am/storage/menu_contents_111/taxret_electronic_25_685e47a4196ac.pdf) contains historical code 244; it is supporting catalogue evidence, not a current year/version selector. Form 240 is identified by its profit-tax calculation title; form 244 by its entrepreneur/notary social calculation title, with stamp wording in the revised version. Match number, full Armenian title, year and applicable help; do not transplant a quarterly form route, row ID or period code.

Useful labels observed in the same portal for quarterly work are **Անավարտ հաշվետվություններ** (unfinished drafts), **Լրացված հաշվետվություններ** (completed reports), and **Հանձնված հաշվետվություններ** (filed reports). Reconfirm current labels. Search the filed archive for the exact taxpayer/form/year before completed or unfinished lists. A completed report or retained unfinished copy is not proof that a filing is absent.

Record the state of each requested form independently:

| State | Required evidence and next action |
|---|---|
| Unsigned draft | Reopen and verify its persisted year/version/amounts; a draft request stops here. |
| Completed unsigned report | Inspect its actual contents and authorization before starting signing. |
| Signed report awaiting submission | Reuse the matching report if filing is authorized; do not create another signing challenge. |
| Submitted with unknown outcome | Inspect completed reports and archive before any retry. |
| Accepted/valid | Verify exact identity/year/form and retrieve filed copy and receipt; stop submission attempts. |

## Save and reopen

Set year and any required period/version controls first, resolving confirmations before amounts because a change can clear entries. Inspect whether each field is editable or calculated. Use the current temporary-save control; **Հիշել Ժամանակավորապես** was observed for quarterly work. Reopen the exact saved annual draft from its list entry and compare taxpayer, form/version, year, amounts and calculated sections with the worksheet.

Do not claim annual fields share quarterly IDs or that a value has persisted because the page still displays it. An unexpected readonly total calls for normal save/reopen and current help inspection, not forced field writes. Preserve unrelated drafts and accepted reports.

## Filing and interrupted operations

A filing request authorizes preparing the concrete review; signing/submission must also satisfy the current browser tool's action-time confirmation requirements. Confirm each exact form and year covered by the request. Keep the user's phone PIN/OTP with them. Do not repeat a pending signing challenge.

Registration, signing, sending, acceptance and payment are distinct states. After sending, verify the exact archive entry and its current accepted/valid status rather than relying solely on a success banner. Retrieve the signed filed copy and acceptance receipt through observed current links; never manufacture report references or reuse another filing's download URL.

When a response is interrupted or unknown, first inspect the corresponding completed and archived report. If accepted, retrieve evidence without resubmitting. If signed but unsent, continue from that stage within the existing authorization. If still ambiguous, preserve the page and report what cannot be established. In a two-form bundle, avoid repeating the form that already succeeded.

An offer for early liability settlement or return of credits to the unified account is a separate financial action; decline it unless separately authorized. A failed preview/download requires document recovery, not another filing or a bypass of browser security. Store taxpayer documents, receipts and worksheets privately outside the public skill package.
